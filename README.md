# peterbacalso.com

Personal site and blog built with Astro 5, Tailwind v4, and Markdown. Deployed to GitHub Pages at [peterbacalso.com](https://peterbacalso.com).

## Quickstart

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # production build → dist/
```
